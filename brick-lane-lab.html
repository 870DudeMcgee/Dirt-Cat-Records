Step 3 · Advanced hardware setup

Program the Enigma parameters

The colored LED patterns below are recall instructions for the hidden menus—not extra front-panel meters.

1

Enable access
Set side-panel DIP switch 6 to ON.

2

Enter a menu
Long-press left for Enigma Left or right for Enigma Right (2 seconds).

3

Program and exit
Short left selects a parameter; short right changes its value. Long-press either direction to exit.

Stereo pair: program Enigma from the parent module. Turn Optosync off before changing a child for mono use.
